Modifications by English Assist contributors (2026):
- Extract English POS, Chinese definitions and IPA from ECDICT for the English
  completion vocabulary and English words referenced by CC-CEDICT.
- Normalize CC-CEDICT tone-number pinyin to lowercase untoned search keys;
  select single-word English glosses, join them to ECDICT and rank them using
  the attributed English frequency list; bound each key to 64 matches.
- Compile separate indexes and strings into english-lexicon-v1.bin (RTENLX01).

Reproducibility:
The source distribution includes losslessly compressed originals and a standalone
Python compiler in tools/english-assist/build-lexicon.py. Frozen repository commits,
original Git blob IDs, compressed/content SHA256 values and license SHA256 values
are recorded in data/dict/raw/english-assist/SOURCES.json (installed as
english-lexicon-sources.json). The actual output digest/counts are recorded in
english-lexicon-v1.json beside the binary. The installed binary can be used and
redistributed separately under the data terms above.
