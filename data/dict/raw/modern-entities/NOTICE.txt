This is a bounded typed Chinese-covered projection, not a complete Wikidata dump,
a comprehensive modern-name dictionary or a currentness guarantee. The frozen
expanded snapshot includes exact WDQS queries/limits, discovery IDs and categories,
real wbgetentities revision numbers and response digests. Selected source fields
include English/Chinese labels, descriptions, aliases, instance-of, official-site
claims and source sitelink counts. It is a deterministic field projection, not an
unmodified HTTP response. Queries that timed out supplied no admitted source data.

Runtime entries require usable ASCII English spelling and real Chinese metadata.
An upstream Chinese description is short entity metadata, not a dictionary
entry; if absent, a real Chinese label is combined with the discovered category.
The origin of each Chinese display string is explicit. Original 51 project-reviewed
Chinese summaries, spellings and aliases are preserved in reviewed-seed-v1.json
with their original verified revisions, not relabelled as upstream translations.
These project catalog contributions are also provided under CC0 1.0.

Ranking uses the frozen sitelink count as a visibility proxy, with bounded category
and reviewed-seed tie preferences. It is not typing frequency or live popularity.
Different QIDs may share an alias; their separate meanings and source identities
are retained. Optional official-site links document identity only: website prose,
logos and other assets are not included or relicensed. Names may be trademarks.
No source project, company or product endorses English Assist.

Approved catalog: data/dict/modern-entities.json
Embedded runtime: data/dict/modern-entities.tsv
Normal offline check: tools/english-assist/modern-entities.py --check
Explicit saved-response import writes a separate proposal directory:
  modern-entities.py --import-research <saved-responses> --output-proposal <new-dir>
Explicit network revision refresh writes a separate proposal JSON:
  modern-entities.py --propose-refresh <new-review.json>
Neither operation replaces approved data. Review identity, source Chinese, aliases,
filtering, revisions and rank policy before admitting a proposal and regenerating.
Typing and normal builds do not fetch, translate or refresh data. The independent
producer and runtime retain the repository MIT software license.
