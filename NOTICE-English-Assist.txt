# English Assist - third-party notices

English Assist is derived from retype (MIT), frozen upstream commit
902e35e06ee4f744320cf995c39b1f64693034cf.
Copyright (c) 2026 retype contributors. See LICENSE for the complete code license.
Internal retype-* filenames identify inherited components in this independent build.

The English Assist Windows package contains the offline English frequency image
and the separate English lexicon metadata file, including selected Chinese
headwords/readings and word-frequency evidence. Complete upstream Chinese
base/classification dictionary images are not installed. Notices for data retained in the source
tree and the original upstream build are in the source distribution NOTICE.txt.

## English word frequencies
- Source: https://github.com/wolfgarbe/SymSpell, commit c239062ae02961df18ab7da1671d01b4388204e0
- File: SymSpell/frequency_dictionary_en_82_765.txt, by Wolf Garbe.
- Upstream combines SCOWL word lists (Kevin Atkinson and contributing word-list authors)
  with Google Books Ngram frequencies (https://books.google.com/ngrams/).
- Google Ngram data is licensed under CC BY 3.0; SCOWL carries its own word-list
  notices and permissions. See LICENSE-Google-Ngram, LICENSE-SCOWL and LICENSE-SymSpell.
- retype filters unsupported non-ASCII entries and precompiles prefix indexes;
  spelling suggestions use an independently implemented bounded one-edit search.
- The compiled English data retains its upstream notices and applicable data licenses;
  those licenses are separate from retype's MIT code license.

## Embedded English bigram preferences

- Source: https://github.com/wolfgarbe/SymSpell, commit c239062ae02961df18ab7da1671d01b4388204e0
- Published file: SymSpell/frequency_bigramdictionary_en_243_342.txt, by Wolf Garbe.
- The exact frozen file contains 242,342 distinct pairs (despite the upstream filename),
  5,137,213 bytes, SHA256 fd892a160184101dd7ae807ac5a302d01fcea1c47304181a8ed7ed9c94545bcd.
- This existing file is distributed under the upstream repository's MIT declaration;
  the complete copyright and permission notice is included as LICENSE-SymSpell.
- English Assist losslessly freezes this file and independently compiles its pairs
  and counts into an embedded binary with sorted lookup and range-maximum indexes.
  No Gboard model or Google trademark is included.
- The precise upstream bigram generation chain is not established by the cited
  documentation. This product does not claim to regenerate it from Google Books V3.
  The unigram Google Ngram/SCOWL notices above remain separately applicable.
- Frozen source/license hashes and the deterministic compiler are in the matching
  source archive at data/dict/raw/english-bigrams and tools/english-assist;
  installed build.json records the embedded image/compiler/source summary.

## English definitions, POS, IPA and pinyin lookup

The separate english-lexicon-v2.bin (RTENLX02) data file is compiled from ECDICT
(MIT), CC-CEDICT (CC BY-SA 3.0, unchanged 2017-11-17 snapshot), the English frequency
list above and Wanxiang Chinese frequencies (CC BY 4.0).
It preserves Chinese headwords, numbered-tone readings, source glosses, Chinese
frequencies and source/usage evidence. Reverse ECDICT links use exact complete
Chinese gloss items; word-level ranking distinguishes exact pinyin from expansion.
CC-CEDICT-derived adapted metadata retains CC BY-SA 3.0; the independent ECDICT
MIT and Wanxiang CC BY 4.0 terms/attributions also remain applicable.
Wanxiang inputs are zi.dict.yaml and jichu.dict.yaml from amzxyz/rime-wanxiang
v18.0.14 (https://github.com/amzxyz/rime-wanxiang/releases/tag/v18.0.14).
See NOTICE-English-Lexicon.txt for source authors, the original CC-CEDICT header,
modification details and source/compiled hashes; see LICENSE-ECDICT,
LICENSE-CC-CEDICT and the full installed LICENSE-Wanxiang for source licenses.
The code license remains MIT. Sources and the independent compiler are included
in the matching source distribution. No source project endorses this product.

## Limited modern company/product names

- A separate reviewed seed of 51 AI companies/products and developer-tool
  names is embedded as EAMODEN1. It is not a complete modern-entity or Wikidata corpus.
- Structured IDs, source descriptions and exact revisions come from Wikidata under
  CC0-1.0 (https://www.wikidata.org/wiki/Wikidata:Licensing); the approved catalog
  records each QID, revision URL and official-site reference. Chinese summaries
  and normalized aliases are reviewed for this limited seed.
- Example: Anthropic, Q116758847 revision 2562358338
  (https://www.wikidata.org/w/index.php?title=Q116758847&oldid=2562358338),
  official reference https://www.anthropic.com/company.
- Official-site links document identity; their site prose, logos and other assets
  are not declared CC0 or included merely because those links are recorded.
- Approved JSON, runtime TSV and the frozen structured snapshot/provenance are
  included in the matching source distribution under data/dict/modern-entities*
  and data/dict/raw/modern-entities/. Installed build.json records the actual
  approved count and JSON/TSV digests; the TSV is embedded in the native binary.
- The independent catalog-checking and runtime code is MIT. Updates require an
  explicit offline review/regeneration workflow; typing does not fetch live data.
